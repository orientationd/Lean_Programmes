# Moteur « Exemple équilibre »

Exemple de moteur contribué, à copier pour proposer le sien. Il se situe
entre les moteurs « demande » et « offre » du socle. Les paramètres et
leur justification sont dans `Moteur.lean` ; les résultats de tous les
programmes sous ce moteur apparaissent dans le rapport et dans la
synthèse (`scripts/synthese_pdf.py out/synthese.json out/synthese.pdf
--moteur ExempleEquilibre`).
